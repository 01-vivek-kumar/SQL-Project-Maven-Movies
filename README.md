# SQL Project: Maven Movies 
## Project Overview

**Project Title**: Maven Movies Analysis
**Level**: Advanced 
**Database**: `mavenmovies`

I conducted this project to analyze rental trends, customer behavior, and revenue patterns using SQL queries. The project is based on the Maven Movies dataset, which contains information about films, customers, rentals, and payments. Through this project, I have applied various SQL techniques, including Joins, Window Functions, Common Table Expressions (CTEs), and Aggregations, to extract meaningful insights from the data.


## Objectives

1. **Set up a database**: Create and populate a database with the provided movie data.
2. **Data Cleaning**: Identify and remove any records with missing or null values.
3. **Exploratory Data Analysis (EDA)**: Perform basic exploratory data analysis to understand the dataset.
4. **Business Analysis**: Use SQL to answer specific business questions and derive insights from the sales data.

## Project Structure

### 1. Database Setup

- **Database Creation**: The project starts by creating a database named `mavenmovies`.
- **Table Creation**: The dataset consists of multiple tables, each holding crucial information:
  
film - Contains details about each movie, including title, rental rate, and language.
customer - Stores customer information, such as first and last names, addresses, and
store associations.
rental -  Records each rental transaction with rental dates and customer details.
payment -  Holds information about payments made by customers for their rentals.
actor -  Lists actors with their first and last names.
film_actor - Connects films with actors, showing which actor appeared in which movie.
inventory -  Manages copies of films available in different stores.
language - Stores information about the languages of films.

### 2. Data Analysis & Findings

The following SQL queries were developed to answer specific business questions starting from basics to advance **covering Functions and GROUP BY Analysis, Joins for Data Retrieval, Window Functions for Ranking & Trends, CTEs**

1. **Retrieve the total number of rentals made in the Sakila database**:
```sql
SELECT COUNT(RENTAL_ID) AS TOTAL_RENTALS
FROM RENTAL;
```

2. **Find the average rental duration (in days) of movies rented from the Sakila database**:
```sql
SELECT AVG(DATEDIFF(LAST_UPDATE, RENTAL_DATE)) AS AVG_RENTAL
FROM RENTAL;

```

3. **Display the first name and last name of customers in uppercase**:
```sql
SELECT UPPER(CONCAT(FIRST_NAME, ' ', LAST_NAME)) AS CUSTOMER_NAME
FROM CUSTOMER;

```


4. **Extract the month from the rental date and display it alongside the rental ID**:
```sql
SELECT RENTAL_ID, MONTH(RENTAL_DATE) 
FROM RENTAL;
```

 
5. **Retrieve the count of rentals for each customer (display customer ID and the count of rentals)**:
```sql
SELECT CUSTOMER_ID, COUNT(RENTAL_ID) AS RENTAL_COUNT
FROM RENTAL 
GROUP BY CUSTOMER_ID;

```


 
6. **Find the total revenue generated by each store**:
```sql
SELECT S.STORE_ID, SUM(P.AMOUNT) AS REVENUE
FROM CUSTOMER C
JOIN PAYMENT P ON C.CUSTOMER_ID = P.CUSTOMER_ID
JOIN STORE S ON S.STORE_ID = C.STORE_ID
GROUP BY S.STORE_ID;
```



7. **Determine the total number of rentals for each category of movies**:
```sql
SELECT C.NAME AS CATEGORY_NAME, COUNT(R.RENTAL_ID) AS RENTAL_NO 
FROM CATEGORY C 
JOIN FILM_CATEGORY FC ON C.CATEGORY_ID = FC.CATEGORY_ID
JOIN INVENTORY I ON I.FILM_ID = FC.FILM_ID
JOIN RENTAL R ON R.INVENTORY_ID = I.INVENTORY_ID 
GROUP BY C.NAME
ORDER BY RENTAL_NO DESC;

```

 
8. **Find the average rental rate of movies in each language**:
```sql
SELECT L.NAME, AVG(F.RENTAL_RATE) AS AVG_RATE
FROM FILM F
JOIN LANGUAGE L ON F.LANGUAGE_ID = L.LANGUAGE_ID
GROUP BY L.NAME;
```

## Joins 

**9. Display the title of the movie, customer's first name, and last name who rented it.**  
```sql
SELECT F.TITLE, C.FIRST_NAME, C.LAST_NAME
FROM FILM F 
JOIN INVENTORY I ON F.FILM_ID = I.FILM_ID 
JOIN RENTAL R ON R.INVENTORY_ID = I.INVENTORY_ID 
JOIN CUSTOMER C ON C.CUSTOMER_ID = R.CUSTOMER_ID;

```

**10. Retrieve the names of all actors who have appeared in the film "Gone with the Wind."**  
```sql
SELECT A.FIRST_NAME, A.LAST_NAME
FROM FILM_ACTOR FA 
JOIN FILM F ON FA.FILM_ID = F.FILM_ID 
JOIN ACTOR A ON A.ACTOR_ID = FA.ACTOR_ID 
WHERE F.TITLE = 'GONE WITH THE WIND';
```

**11. Retrieve the customer names along with the total amount they've spent on rentals.**  
```sql
SELECT CONCAT(FIRST_NAME, ' ', LAST_NAME) AS C_NAME, SUM(AMOUNT) AS AMOUNT
FROM CUSTOMER C 
JOIN PAYMENT P ON C.CUSTOMER_ID = P.CUSTOMER_ID
JOIN RENTAL R ON R.CUSTOMER_ID = C.CUSTOMER_ID 
GROUP BY C.CUSTOMER_ID, C_NAME; -- Grouping by customer ID ensures accuracy
```

**12. List the titles of movies rented by each customer in a particular city (e.g., 'London').**  
 
```sql
SELECT CONCAT(C.FIRST_NAME, ' ', C.LAST_NAME) AS C_NAME, F.TITLE, CI.CITY
FROM CUSTOMER C 
JOIN ADDRESS A ON C.ADDRESS_ID = A.ADDRESS_ID 
JOIN CITY CI ON A.CITY_ID = CI.CITY_ID   
JOIN RENTAL R ON R.CUSTOMER_ID = C.CUSTOMER_ID  
JOIN INVENTORY I ON I.INVENTORY_ID = R.INVENTORY_ID 
JOIN FILM F ON F.FILM_ID = I.FILM_ID 
WHERE CI.CITY = 'London'  
GROUP BY C.CUSTOMER_ID, F.TITLE, CI.CITY;  
```

**13. Display the top 5 rented movies along with the number of times they've been rented.**  
 
```sql
SELECT F.TITLE, COUNT(R.RENTAL_ID) AS RENTAL_COUNT
FROM FILM F
JOIN INVENTORY I ON F.FILM_ID = I.FILM_ID  
JOIN RENTAL R ON R.INVENTORY_ID = I.INVENTORY_ID 
GROUP BY F.TITLE
ORDER BY RENTAL_COUNT DESC
LIMIT 5;
```

**14. Determine the customers who have rented movies from both stores (store ID 1 and store ID 2).**  
 
```sql
SELECT C.CUSTOMER_ID, CONCAT(C.FIRST_NAME, ' ', C.LAST_NAME) AS CUSTOMER_NAME
FROM RENTAL R 
JOIN INVENTORY I ON R.INVENTORY_ID = I.INVENTORY_ID 
JOIN CUSTOMER C ON C.CUSTOMER_ID = R.CUSTOMER_ID
WHERE I.STORE_ID IN (1, 2)
GROUP BY C.CUSTOMER_ID, CUSTOMER_NAME
HAVING COUNT(DISTINCT I.STORE_ID) = 2;
```

## Windows Function 

**1. Rank the customers based on the total amount they've spent on rentals.**  

```sql
SELECT A.CUSTOMER, A.AMOUNT_SPENT, DENSE_RANK() OVER( ORDER BY A.AMOUNT_SPENT DESC) AS RANKING 
FROM
(SELECT CONCAT(C.FIRST_NAME, ' ', C.LAST_NAME) AS CUSTOMER,  SUM(P.AMOUNT) AS AMOUNT_SPENT 
FROM RENTAL R 
JOIN PAYMENT P ON R.RENTAL_ID = P.RENTAL_ID 
JOIN CUSTOMER C ON C.CUSTOMER_ID = P.CUSTOMER_ID 
GROUP BY C.FIRST_NAME, C.LAST_NAME
) A;
```

**2. Calculate the cumulative revenue generated by each film over time.**  

```sql
SELECT 
    F.TITLE, 
    P.PAYMENT_DATE, 
    SUM(P.AMOUNT) OVER (PARTITION BY F.TITLE ORDER BY P.PAYMENT_DATE) AS CUMULATIVE_REVENUE
FROM PAYMENT P
JOIN RENTAL R ON P.RENTAL_ID = R.RENTAL_ID
JOIN INVENTORY I ON R.INVENTORY_ID = I.INVENTORY_ID
JOIN FILM F ON I.FILM_ID = F.FILM_ID
ORDER BY F.TITLE, P.PAYMENT_DATE;

```
**3. Determine the average rental duration for each film, considering films with similar lengths.**  

```sql
SELECT 
    F.TITLE, 
    F.LENGTH,
    F.RENTAL_DURATION, 
    AVG(F.RENTAL_DURATION) OVER (PARTITION BY F.LENGTH) AS AVG_RENTAL_DURATION
FROM FILM F;
```

**4. Identify the top 3 films in each category based on their rental counts.**  

```sql
SELECT TITLE, NAME AS CATEGORY_NAME, RENTAL_COUNT, RENTAL_RANK
FROM (
    SELECT 
        F.TITLE, 
        C.NAME, 
        COUNT(R.RENTAL_ID) AS RENTAL_COUNT, 
        DENSE_RANK() OVER(PARTITION BY C.NAME ORDER BY COUNT(R.RENTAL_ID) DESC) AS RENTAL_RANK
    FROM FILM F 
    JOIN FILM_CATEGORY FC ON F.FILM_ID = FC.FILM_ID 
    JOIN CATEGORY C ON C.CATEGORY_ID = FC.CATEGORY_ID 
    JOIN INVENTORY I ON I.FILM_ID = F.FILM_ID
    JOIN RENTAL R ON R.INVENTORY_ID = I.INVENTORY_ID
    GROUP BY F.TITLE, C.NAME
) A
WHERE RENTAL_RANK <= 3;

```

**5. Calculate the difference in rental counts between each customer's total rentals and the average rentals across all customers.**  

```sql
WITH CustomerRentalCount AS (
    SELECT 
        C.CUSTOMER_ID, 
        CONCAT(C.FIRST_NAME, ' ', C.LAST_NAME) AS CUSTOMER_NAME,
        COUNT(R.RENTAL_ID) AS TOTAL_RENTALS
    FROM rental R
    JOIN customer C ON R.customer_id = C.customer_id
    GROUP BY C.CUSTOMER_ID, CUSTOMER_NAME
)
SELECT 
    CUSTOMER_ID, 
    CUSTOMER_NAME, 
    TOTAL_RENTALS, 
    ROUND(TOTAL_RENTALS - AVG(TOTAL_RENTALS) OVER (), 2) AS RENTAL_DIFF
FROM CustomerRentalCount
ORDER BY RENTAL_DIFF DESC;
```

**6. Find the monthly revenue trend for the entire rental store over time.**  

```sql
SELECT 
    YEAR(P.PAYMENT_DATE) AS YEARLY, 
    MONTH(P.PAYMENT_DATE) AS MONTHLY, 
    SUM(P.AMOUNT) AS TOTAL_REVENUE
FROM payment P
JOIN customer C ON P.customer_id = C.customer_id
JOIN store S ON C.store_id = S.store_id
GROUP BY YEARLY, MONTHLY
ORDER BY YEARLY, MONTHLY;
```

**7. Identify the customers whose total spending on rentals falls within the top 20% of all customers.**  

```sql
WITH CustomerSpending AS (
    SELECT 
        C.CUSTOMER_ID, 
        CONCAT(C.FIRST_NAME, ' ', C.LAST_NAME) AS NAME, 
        SUM(P.AMOUNT) AS TOTAL_SPEND
    FROM payment P
    JOIN customer C ON P.customer_id = C.customer_id
    GROUP BY C.CUSTOMER_ID, NAME
), RankedCustomers AS (
    SELECT *, 
           PERCENT_RANK() OVER (ORDER BY TOTAL_SPEND DESC) AS RANK_PERCENTILE
    FROM CustomerSpending
)
SELECT CUSTOMER_ID, NAME, TOTAL_SPEND
FROM RankedCustomers
WHERE RANK_PERCENTILE <= 0.2  -- Top 20% customers
ORDER BY TOTAL_SPEND DESC;
```

**8. Calculate the running total of rentals per category, ordered by rental count.**  

```sql
WITH CategoryRentalCount AS (
    SELECT 
        C.NAME AS CATEGORY, 
        COUNT(R.RENTAL_ID) AS RENTAL_COUNT
    FROM rental R
    JOIN inventory I ON R.inventory_id = I.inventory_id
    JOIN film_category FC ON I.film_id = FC.film_id
    JOIN category C ON FC.category_id = C.category_id
    GROUP BY C.NAME
)
SELECT 
    CATEGORY, 
    RENTAL_COUNT, 
    SUM(RENTAL_COUNT) OVER (ORDER BY RENTAL_COUNT DESC) AS RUNNING_TOTAL
FROM CategoryRentalCount
ORDER BY RENTAL_COUNT DESC;
```

**9. Find the films that have been rented less than the average rental count for their respective categories.**  

```sql
WITH FilmRentalCount AS (
    SELECT 
        F.FILM_ID, 
        F.TITLE, 
        C.CATEGORY_ID, 
        C.NAME AS CATEGORY, 
        COUNT(R.RENTAL_ID) AS RENTAL_COUNT
    FROM rental R
    JOIN inventory I ON R.inventory_id = I.inventory_id
    JOIN film F ON I.film_id = F.film_id
    JOIN film_category FC ON F.film_id = FC.film_id
    JOIN category C ON FC.category_id = C.category_id
    GROUP BY F.FILM_ID, F.TITLE, C.CATEGORY_ID, C.NAME
),
CategoryAverageRental AS (
    SELECT 
        CATEGORY_ID, 
        AVG(RENTAL_COUNT) AS AVG_RENTAL_COUNT
    FROM FilmRentalCount
    GROUP BY CATEGORY_ID
)
SELECT 
    FRC.FILM_ID, 
    FRC.TITLE, 
    FRC.CATEGORY, 
    FRC.RENTAL_COUNT, 
    CAR.AVG_RENTAL_COUNT
FROM FilmRentalCount FRC
JOIN Category
```


**10. Identify the top 5 months with the highest revenue and display the revenue generated in each month.**  

```sql
SELECT 
    DATE_FORMAT(payment_date, '%Y-%m') AS month_year,  -- Extract month and year
    SUM(amount) AS total_revenue
FROM payment
GROUP BY month_year
ORDER BY total_revenue DESC
LIMIT 5;
```
